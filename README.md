# 🚀 2048 · 星域合成

> 🌌 一款运行在 **快应用 (Quick App)** 上的星空主题 2048 小游戏，滑动合成，点亮你的星域。

## ✨ 游戏特色

- 🎇 **星域合成** —— 数字方块化作星尘，碰撞融合，逐级进阶
- 🌠 **梦幻渐变** —— 2 → 8192 每一级都有专属星云配色
- 🎯 **滑动操作** —— 四向轻扫即可移动合成，上手零门槛
- 🏆 **积分榜** —— 本地记录 Top5 最高分与历史战绩

## 🎨 星云配色（数值阶梯）

| 数值 | 主色 | 亮点 |
| :--: | :--: | :--: |
| 2    | 冰蓝 | `#2f86c9` |
| 8    | 翠绿 | `#2ec4a0` |
| 32   | 琥珀 | `#e8b83a` |
| 128  | 绯红 | `#ef5350` |
| 512  | 星紫 | `#9c5cff` |
| 2048 | 纯白星辰 | `#ffffff` |

## 🕹️ 玩法

1. 向 **上 / 下 / 左 / 右** 滑动棋盘
2. 相同数字相邻即**碰撞合成**，数值翻倍
3. 合成出 **2048**（或更高）即达星域巅峰
4. 棋盘积满即为终结，冲击更高纪录！
